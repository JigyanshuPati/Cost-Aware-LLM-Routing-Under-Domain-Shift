# Cost-Aware LLM Routing Under Domain Shift

A cheap model fails on some queries. Predicting which ones before generation lets you escalate only those to an expensive model. Linear probes on Qwen2.5-0.5B final-token hidden states (25 layers) predict failure at 0.68 AUC, with no generation. Labels are pass rates over 8 samples on 2,500 GSM8K/MBPP/MMLU queries; MBPP is graded by executing its unit tests. Residualising all 896 dimensions against token count rules out prompt length: the probe still beats that baseline by +0.06 AUC. Against six routers on identical labels, it captures 32% of oracle gain at 30% escalation. Under domain shift it fails twice: cross-domain AUC drops to 0.55, and a fixed threshold escalates 55% instead of the budgeted 30%. Routers must be fit per domain — the transfer failure is the finding.
